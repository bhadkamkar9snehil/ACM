ACM Guide & Architecture
ACM (Asset Condition Monitor) is an unsupervised machine learning platform that monitors industrial assets (wind turbines, pumps, generators) with no labels, no training data, and no manual tuning. It learns what "normal" looks like from the first tick and automatically sets anomaly thresholds.

It ingests raw data via CSV files, OPC UA streams, or SQL databases.
01 / Operator
Goal: Monitor fleet-wide health at a glance.
  • KPIs: Live tally of how many assets are fully healthy vs in alarm state.
  • Health Badges: Every asset gets a badge. Green = OK. Red = Active Alarm.
  • Timelines: Click an asset to see its historical alarms chronologically.
  • Acknowledge: Click an active alarm to "Ack" it with a note, silencing its pager alerts.
02 / Reliability Engineer
Goal: Deep dive into specific assets to diagnose underlying issues.
  • Dropdown: Select the asset you wish to investigate.
  • Fused Anomaly Score: A unified chart tracking the asset's overall health index over time.
  • Detector Heatmap: A breakdown of the 6 individual ML models. Hover over cells to see exactly which models fired.
  • Culprit Sensors: When an alarm fires, ACM ranks the individual sensors responsible so you know exactly what is breaking (e.g. bearing_temp or vibration_x).
03 / Admin & ML Ops
Goal: Configure the platform, onboard new assets, and manage pipelines.
  • Onboard Assets: Register a new asset by pointing ACM to its data source (CSV, OPC UA, or SQL).
  • Run Now: Force ACM to score historical data instantly (great for bulk CSV evaluation).
  • System Config: Tweak ML thresholds, pager limits, and dashboard aesthetics.
  • Logs: Review the background task runner's output to debug ingest failures.
04 / Simulate
Goal: Stream synthetic data or real CSVs into ACM to see how it reacts.
  • Generate: Create programmatic synthetic data (Sine waves, Random Walk, Spikes) to test basic detector capabilities.
  • Files (Replay): Upload real-world CSV files (like the CARE dataset). Click Replay to stream the file line-by-line into the system as if it were a live asset.
  • Viewing Live Replays: Configure Replay with OPC-UA publisher and click Start — ACM automatically registers the simulator/opc_ua asset and begins scoring live data. Watch it in the Reliability Engineer tab.
